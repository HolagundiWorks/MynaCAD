# App audit: layout, workflow and missing implementation (2026-11-02)

Scope: MynaCAD 1.2.x in the suite (launcher, MynaHub, MynaOps), read from the code, the docs (`status.md`, `KNOWN_ISSUES.md`,
`parity-checklist.md`) and the screens of the installed builds 1.2.0 to 1.2.11. Counts come from `aad-cli commands` and
`aad-cli auditor` on this build. Nothing here was measured on a clean machine.

## 1. Facts

| Measure | Value |
|---|---|
| Engine commands | 526 |
| Commands with no menu entry | 89 (17 %) |
| Commands with no parameter documentation | 24 (the zoom, pan, regen and select-all family) |
| Menu breadth against the AutoCAD-style list | 185 of 319 items (58 %) |
| Architecture menu | 147 commands in 18 submenus (the largest by far) |
| Engine and host tests | 869 pass |

## 2. Layout: what is wrong now

1. **The Architecture menu is a catalogue, not a workflow.** 147 commands in 18 submenus (Rooms, Text, Standard Layers, Building
   Permission, VH Layers, Project, Take-off, Floors, Electrical, Walls, Parametric, Companion, Structure, Levels and Sections,
   Symbols, AQC Bridge, Levels, Sheet Sets, Sheets). Several groups overlap (Levels, Levels and Sections, Floors, Sheets, Sheet Sets).
2. **Chrome is spread over four edges.** Menu and a tool row at the top; vertical drawing tabs on the left; six vertical panel tabs
   on the right (Properties, Layers, Blocks, Project, History, Revisions) in rotated 11 px text; a level row, a status row and a
   floating ask bar at the bottom. Rotated text is slow to read and the right rail is easy to miss.
3. **The canvas does not show what it is for.** A drawing tab or layout looks the same as the model: no paper frame, no title block,
   no scale. The Model / Page layout toggle changes its label but the canvas did not change visibly in 1.2.10.
4. **Two bars for the same job.** The ask bar and the command line are separate, and the AI chip, command line and prompt each
   have their own focus rules.
5. **Myna gate is silent.** Starting `ODraft.WinUi.exe` without a loaded project exits at once with code 0 and no message.
6. **The status row mixes drawing aids with output settings** (units, paper, orientation, snaps, themes, AI), which is why the page
   settings had to move.

## 3. Layout: proposal

| Area | Proposal |
|---|---|
| Top | Menu bar, then the drawing-tab row (colour chip, name, paper badge, scale). Layer selector at its right end. Model / Sheet segmented toggle in the menu bar. |
| Left | One vertical tool column: select, draw, modify, annotate, architecture. Replaces the top tool row and the left tab rail. |
| Right | One panel with horizontal tabs (Properties, Layers, Blocks, Project, History) instead of rotated text. |
| Bottom | Level codes (L0, L1, -L1), snaps, units, fit-to-sheet check, theme, AI. Nothing about paper. |
| Canvas | The active tab draws its sheet frame, margin and title block at its scale; the Design drawing is faded behind. |
| Architecture menu | Regroup by task: Plan (walls, doors, windows, rooms), Structure (grids, columns, lintels, stairs), Sheets, Quantities, Services, Project. Fold the AQC and Companion items into Project. |
| Command access | A command palette (Ctrl+K) over all 526 commands, because 89 have no menu and the menu is only 58 % of the AutoCAD list. |
| First run | When there is no project, show a message that says to pick one in Myna, with a button that opens Myna. |

## 4. Workflow

1. Launcher: sign in, pick the project, open the app (works; single-instance fixed in 1.2.2).
2. Design: draw the building once, on levels (L0 at the datum, negative below).
3. Add tabs from a template: paper, scale, layers, styles and symbols in one step (today `sheetset.standard` makes five fixed tabs).
4. Annotate on the tab: objects go on the tab's layers and styles (exists).
5. Check: warn when content does not fit the sheet (missing).
6. Publish: one PDF per tab and a take-off record to MynaOps (batch plot and `takeoff.record` exist; one action does not).
7. Revisions and milestones (exist; not reachable from the tab row).

## 5. Missing or incomplete implementation

### In this work, not yet built or checked on screen
- Page size and orientation per tab: engine command `sheet.page` done and tested; the flyout and the right-click "Page size…" are untested on screen.
- Scale per tab, tab templates, sheet frame, fit check and publish: not built.
- Tab row at the top and tool column at the left: designed, not built.
- Two-pick door and window placement: engine done and tested; the pick prompts are untested on screen.
- Levels window with the datum and automatic elevations: compiles, untested on screen.
- Origin "+" and "O" mark, and the origin as a snap point: drawn and engine-tested; the snap is untested on screen.
- Light mode in MynaOps (brush lookup, theme icon, AI chip): built into 1.2.9 and later; not re-checked after the last fixes.
- None of this is committed.

### Known gaps from the docs
- Planned and not implemented: macOS, Linux and web; result tables for the AI agent; agent tools for take-off and schedules; the
  parametric node editor; full AutoLISP; xref and floor-project interface (floor selector, setup wizard, Floor View Manager);
  panels for Opening Schedule, Drawing Explorer, Xrefs, Measurement, Project Navigator; guarding block-definition edits against
  locked layers; user coordinate systems; SHX fonts; conversion of 3D solids, surfaces and meshes; office history mirror.
- 58 % menu breadth: missing items include New and Open Sheet Set, Batch Publish, Package Drawing, DWG Compare, Markup Import, named
  and multiple viewports, UCS icon, attribute display, Zoom Dynamic, Insert DWG Reference.
- Import runs on the UI thread, so a large drawing freezes the window; DWG and PDF import were not tried in the installed build.
- Re-importing a picture onto the same layer is refused (by design) but the message may not be visible in the shell.
- Layer lock and freeze do not cover objects inside block definitions.

### Quality and release
- Installers are unsigned (SmartScreen warns); no clean-machine install test; the wizard pages are not exercised.
- CI: `cad-ci.yml` failed at the formatting step on a recent push; the nightly workflow failed on its last three scheduled runs;
  the MynaCAD #38 and MynaHub #16 pull requests show failing checks. Not investigated.
- `cargo audit` runs only nightly; dependencies are not audited locally.
- Control channel and MCP are loopback only, plaintext, no authorisation.
- The AI assistant (Olmo 3 7B) is hosted by Myna; MynaCAD and MynaOps have no stop-agent switch or per-app permission panel.
- Myna3D: the mark and colour exist; the app does not.

## 6. Suggested order

1. Commit and push the verified work; fix the CI failures.
2. Tab row at the top, tool column at the left, right panel with horizontal tabs.
3. Sheet frame and title block on the canvas; per-tab scale; tab templates.
4. Command palette; regroup the Architecture menu.
5. Fit check and publish; import on a worker thread.
6. Signed installers and a clean-machine install test.
